official-main migration:

```text
/home/darling/ref-thyme
/home/darling/hackios
```

instructions. Statements about charging, Bluetooth, Wi-Fi, thermal control and
repository paths may be superseded by the official-main probes in
`devices/thyme/docs/` and by `devices/thyme/CHECKLIST.md`.
